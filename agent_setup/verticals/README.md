# Verticals

One settings file per ASICS vertical. Every vertical runs the same steps:

1. **Find sources**: the units to assess, their official websites, the Citation Sheet.
2. **Answer questions**: from the reviewed Citation Sheet only.
3. **Score**: from each Step 2 answer and its citation.

What differs is set here: the question bank, what is assessed (`unit`), which agent does
each job in each step, the shared rules, where its city folders go, and its scoring workbook.
See the main README, "Adding a new ASICS vertical".
