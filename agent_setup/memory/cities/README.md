# cities

One note per city, used only when that city runs, by every vertical. Name it after the city
(`<city>.md`, e.g. `bengaluru.md`). Facts here are guidance, not evidence: write anything not
yet confirmed as UNVERIFIED.

Parastatal-only notes for a city (screening lists, exclusions) go in
`verticals/parastatal/<city>-agencies.md`, with `cities: [<city>]` in the settings block, so
that city-level verticals such as UPD don't receive them.

## Template for a new city (copy into `<city>.md`)

```
---
title: <City> - city context (all verticals)
---
- City government: <name>; governing Act: <Act> [UNVERIFIED until fetched].
- Restructuring: <none known | what changed, when, per which source> [UNVERIFIED].
- Known conflicts in earlier drafts: <e.g. two different effective dates; reuse neither>.
- Eras for governance sources: <era names | n/a>.
- Predecessor names that laws may still use: <names | none known>.
- Useful official places to search: <state legislation portal, gazette, legislature papers,
  appointment orders, service-guarantee portal, procurement portal, RTI portal, CAG>.
```
