---
name: read_citation
kind: client
options: []
---
Read more of one Citation Sheet source by its Citation ID (e.g. "BWSSB-07"). Returns the
passages of its saved text most relevant to `query` (or the beginning if no query), with
"[page N]" markers for PDFs.

Only sources in the Citation Sheet you were given can be read; there is no web access. Use it
when the excerpts you were shown don't contain the decisive passage.
