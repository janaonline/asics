- This file is help only. The question's Detailed Methodology is the rule: if this file and the
  methodology differ, follow the methodology and add "CONFIRM: <this file> says X, the
  methodology says Y".
- Questions about institutional design (functions, jurisdiction, board composition, reporting
  lines) are answered from the whole legal stack (Act, Rules, Regulations, notifications);
  name the section/rule.
- Clear mandate is not clear demarcation (DPG 1a and similar; pattern from the pilot
  AI-vs-human audit): a water board's Act may define its functions clearly while the ULG law also gives
  the ULG water-related mandates and a coordination/supervision role over public authorities.
  Demarcation exists only if the law separates the two roles (explicit carve-out, or
  non-overlapping sub-functions). A correct answer reads like: "The parastatal's operational
  mandate is defined, but its responsibilities vis-a-vis the ULG are not clearly separated
  because <ULG provisions>."
  - DPG 1a scenario: if the ULG law assigns the function in any form (incl. coordination/
    supervision) -> Scenario B or C, not A. If assigned to the ULG in law but delivered only by
    the parastatal -> score under B and add "CONFIRM: possible Scenario D (devolved in law,
    delivered by parastatal)". Where functions shifted under recent city-government law, state
    the old and new allocation and flag it.
- Board composition: an elected representative is not a ULG official. A seat vacant because
  elections were not held is a practice fact.
- Cross-cutting laws can supply the mandate (for example a service-guarantee or RTI law): a state
  service-guarantee law whose schedule lists the agency's services creates a time-bound
  service and redress obligation even when the parastatal Act is silent. Cite the schedule
  entry.
- WEBSITE questions (any question whose methodology checks a website): report four
  components separately - Existence; Accessibility (could it be opened?); Currency (dated
  content within the rubric window); Functionality (the feature works: pages load, portals
  accept input, links resolve). Currency and Functionality need a verified saved copy. If the
  page could not be opened automatically, that is NOT evidence the site is non-functional:
  score null, Confidence Low, and say "VERIFICATION-LIMIT" in notes.
- File format (where the methodology scores it): record the actual type (XLSX/CSV/structured HTML vs text PDF vs scanned
  PDF). A scanned or unextractable PDF = 0 for the format half per the rubric.
- Where a question's evidence requirement asks for a dated screenshot, add "Reviewer to capture a dated screenshot per QB evidence requirement".
- Grievance and participation questions need evidence that the channel or consultation exists
  and functions, not just that it is mentioned.
