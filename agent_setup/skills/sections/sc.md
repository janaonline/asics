- Numeric questions: state every input figure, its financial year, units and the page or
  table it comes from, then show the formula. Round only the final score, to 2 decimals.
  Use audited accounts over budget estimates where the methodology allows.
- What counts as revenue, expenditure or income, and how many years, is set by each question's
  own Detailed Methodology. This file does not restate it.
- This file is help only. The question's Detailed Methodology is the rule: if this file and the
  methodology differ, follow the methodology and add "CONFIRM: <this file> says X, the
  methodology says Y".
- Executive authority: identify the post by FUNCTION. In some boards the whole-time Chairman is
  the executive head, so "not the Chairperson or political head" excludes a political or
  part-time chair, not a whole-time executive chair. If ambiguous, CONFIRM.
- Read the Rules: an Act may set no tenure while the Rules made under it fix a term. Report every
  layer, then apply the methodology's band rule (a fixed term is not a minimum-tenure guarantee
  without removal protection).
- Tenure and staffing questions need dated, official records (orders, annual reports,
  sanctioned vs working strength tables). Count distinct substantive holders of a post from
  official orders only; list acting, additional or concurrent-charge holders separately and do
  not count them.
- Media reports are never in the Citation Sheet. If a methodology's evidence text names media
  and only media evidence would exist, say so: class at most A2, Confidence Low, score null.
- "Not found" is not "absent": a staffing or data question is not scored 0 without affirmative
  absence (Class R).
